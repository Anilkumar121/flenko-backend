📖 2-Minute Guide: How to keep data permanent forever (Render PostgreSQL Setup) Click to open
▼

Render par free PostgreSQL database jodna bahut simple hai. Sirf yeh simple steps karein:

  1. Open Render Dashboard.
  2. Click top-right New + > Select PostgreSQL.
  3. Name: flenko-db daalein aur Create Database par click karein (free tier).
  4. Database ready hone ke baad neeche scroll karein aur Internal Database URL (ya External Database URL) copy karein.
  5. Apni Web Service (flenko-backend) par click karein > Left menu se Environment tab open karein.
  6. Ek naya Environment Variable add karein:
    Key: DATABASE_URL
    Value: <Paste your copied PostgreSQL URL here>
  7. Click Save Changes. Render 60 seconds mein restart hoga aur Master Admin auto-seed ho jayega! Aapka saara data permanent ho jayega!
